# JitDub — клиент

Приложение для Windows на Tauri v2: совместная озвучка аниме и фильмов в реальном времени, как совместная
работа в Figma, но с интерфейсом аудиоредактора в духе Adobe Audition. Дизайн и UI-кит — из maistep
(палитра и иконки JetBrains New UI).

## Что умеет

- **Проекты и участники:** вход по логину, код приглашения, роли (владелец / актёр / зритель), кто онлайн.
- **Realtime:** правки всех участников приходят сразу; видно плейхеды и выделение других людей, кто сейчас пишет.
  Отмена и повтор своих действий (Ctrl+Z / Ctrl+Shift+Z).
- **Сценарий:** импорт субтитров `.ass` / `.srt` / `.vtt` (поле Name/Actor из ASS становится персонажем), статусы
  реплик (не записана / записана / принята / переписать), фильтр «мои реплики», назначение актёров на персонажей.
- **Видео:** у каждого участника своя локальная копия (MP4/H.264 или WebM). Текст текущей реплики поверх кадра и
  **лента ритмо** — реплики проезжают через линию синхронизации, растянутые по своей длительности.
- **Мультитрек:** дорожка на каждого актёра (M / S / R, громкость, панорама), клипы с волной, перетаскивание
  между дорожками, подрезка краёв, разрез (S), фейды, привязка к краям, маркеры, повтор диапазона.
- **Запись:** R — с плейхеда на свою дорожку; Shift+R — запись реплики с прероллом, обратным отсчётом и автостопом.
  Запись идёт через AudioWorklet по часам AudioContext, задержка входа и выхода компенсируется,
  дубль сохраняется в WAV без потерь и загружается на сервер.
- **Экспорт:** сведение в стерео-WAV 16/24 бит, по дорожкам в папку или только своя дорожка;
  файл начинается с 00:00 видео.

## Запуск

Нужны Rust (stable) и WebView2 (в Windows 11 есть).

```bash
npm run app          # debug-сборка и запуск
npm run build        # release + установщик NSIS (src-tauri/target/release/bundle)
npm run web          # только интерфейс в браузере: http://localhost:3310
```

Адрес сервера по умолчанию — `https://jitdub.moelibre.cc`. Другой можно указать на экране входа (раздел «Сервер»).

## Устройство

```
src-tauri/        оболочка Tauri: диалоги сохранения и выбора папки, запись файлов, открытие ссылок
ui/index.html     каркас окна
ui/css/           uikit.css (из maistep) + app.css
ui/js/
  main.js         экраны, шапка и транспорт, запись и загрузка дублей, экспорт, настройки, горячие клавиши
  sync.js         документ проекта и WebSocket-синхронизация (оптимистичные операции, rebase, undo/redo)
  audio.js        WebAudio: транспорт, воспроизведение клипов, запись через AudioWorklet, сведение в WAV
  timeline.js     мультитрек: линейка, дорожки, клипы, реплики, плейхеды участников, перетаскивание
  video.js        видео, субтитр поверх кадра, лента ритмо
  script.js       сценарий, импорт субтитров, персонажи
  side.js         инспектор, участники, чат, дубли
  lobby.js        вход и список проектов
```
